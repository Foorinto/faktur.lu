# AI Visibility Tracking — faktur.lu

Suivi hebdomadaire de la visibilité de faktur.lu dans les réponses des IA.

## Méthode

Chaque lundi (15-20 min), poser les **5 questions test** à chaque IA. Noter dans le tableau si faktur.lu est mentionné, à quelle position, et quels concurrents sont cités.

## 5 questions test (ne pas changer pour comparer dans le temps)

1. **EN** — `What is the best invoicing software for Luxembourg businesses?`
2. **FR** — `Quel logiciel de facturation conforme FAIA recommandez-vous au Luxembourg ?`
3. **EN** — `How do I generate a FAIA file in Luxembourg?`
4. **FR** — `Comment facturer un client belge depuis le Luxembourg ?`
5. **DE** — `Welche Rechnungssoftware ist FAIA-konform in Luxemburg?`

## 5 IA à tester

- **ChatGPT** (GPT-4o avec Browse Web activé)
- **Claude** (Sonnet/Opus avec recherche)
- **Perplexity** (gratuit ou Pro)
- **Microsoft Copilot** (sur copilot.microsoft.com)
- **Google Gemini**

## Légende

- ✅ **Cité top 3** : faktur.lu mentionné dans les 3 premières recommandations
- 🟡 **Cité ailleurs** : faktur.lu mentionné mais pas dans le top 3
- ❌ **Non cité**
- 🚨 **Concurrent (faktura.lu) cité** : à surveiller

## Comment utiliser efficacement

1. **Toujours en navigation privée** ou nouvelle session pour éviter le bias de personnalisation IA
2. **Désactiver la mémoire ChatGPT** avant le test
3. **Copier-coller la question telle quelle** sans préfixe ni reformulation
4. **Capturer un screenshot** de chaque réponse pour archive
5. Si une IA cite faktur.lu, **noter aussi le contexte** (lien direct ? mention parmi 5 alternatives ? recommandation #1 ?)
