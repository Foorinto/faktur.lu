## #8 — "What is the difference between Factur-X, ZUGFeRD, and UBL?"

**Question type** : Technique
**Mots-clés** : Factur-X vs ZUGFeRD vs UBL, e-invoicing formats

**Structure** :
- Factur-X (FR) : PDF avec XML embedded (CII format), B2B France
- ZUGFeRD (DE) : très proche de Factur-X (CII), B2B Allemagne
- UBL (EN) : XML pur sans PDF, format Peppol BIS 3.0
- Quand utiliser quoi :
  - B2B Allemagne → ZUGFeRD
  - B2B France → Factur-X
  - B2G/B2B EU mandatory → UBL (Peppol)
- Outils qui supportent les 3 : faktur.lu
